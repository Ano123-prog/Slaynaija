# SlayNaija Community — starter prototype

A mobile-first visual prototype using plain HTML, CSS and JavaScript.

## Preview
Open `index.html` in a browser or deploy these files to a static host.

## Current scope
- Luxury burgundy, gold-beige and off-white visual direction
- Discover landing screen
- Fashion category tabs
- Trending style cards with interactive favourites
- Community preview
- Bottom navigation with placeholder notices
- Basic PWA manifest and service worker

## Important
This is a front-end prototype only. It does **not** include real accounts, database storage, uploads, payments, messaging, moderation, or secure role enforcement. No Supabase connection or SQL has been added. Do not collect real user information yet.

The existing Supabase `comments` table is not referenced or modified by this project.
